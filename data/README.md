# data/

Canonical tables live here once the facts-only export is built and the source terms are settled.
See [../docs/SCHEMA.md](../docs/SCHEMA.md).

- `chaffee-county/`: the first slice, built for the Chaffee Provides relaunch with Guidestone Colorado.
  Generated by `scripts/build_tables.py` from the Phase 2 raw CSV. Do not edit by hand.
  `_deferred_organizations.csv` holds food banks and organizations, which the schema defers to v2.
- `id_registry.csv`: stable IDs. A business keeps its ID across runs and IDs are never reused.

Not released: this repo is private and the slice has not been through the source-terms review.
- `partner-additions/`: rows supplied by partners in the raw layout, merged in by `--additions`. A row replaces the raw row with the same Source ID and is marked partner-verified.
